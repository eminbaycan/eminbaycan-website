# Emin Baycan - Personal Portfolio & Resume Web Application

Modern, duyarlı ve performanslı kişisel web sitesi ve dijital CV uygulaması.

---

## 🚀 Özellikler (Features)

- **🌐 Çift Dil Desteği (TR / EN):** Tüm içerik Türkçe ve İngilizce olarak anında değiştirilebilir.
- **📄 İnteraktif Dijital CV:** İş deneyimleri, eğitim geçmişi, yetenekler ve sertifikaların sergilendiği, çıktı/PDF almaya uygun sayfa düzeni.
- **📝 Blog Sayfası:** Teknoloji, sistem yönetimi ve IT deneyimleri üzerine makaleler.
- **🔒 DevTools Koruması & Eğlenceli `/caught` Sayfası:** F12 veya klavye kısayolları ile geliştirici araçları açıldığında veya kod incelenmeye çalışıldığında kullanıcıyı dinamik istatistiklerin yer aldığı eğlenceli `/caught` sayfasına yönlendirir.
- **⚡ Canlı İstatistikler & Dinamik Ölçüm:** Geliştirici sayfasında gerçek zamanlı sayfa yüklenme hızı (Performance API), dosya/kod satırı sayıları ve performans skorları.
- **🎨 Modern Tasarım & Tema Desteği:** Sticky üst navigasyon barı, yumuşak geçiş efektleri, karanlık/aydınlık tema uyumu ve responsive (mobil uyumlu) yapı.
- **✨ Hareketli Başlık ve Dinamik Favicon:** Sekme başlığında akan metin ve periyodik değişen emoji icon animasyonu.

---

## 🛠️ Teknolojiler (Tech Stack)

- **Frontend:** React 19, TypeScript, Vite
- **Stil & Tasarım:** Tailwind CSS v4, Lucide React (İkonlar), Motion (Animasyonlar)
- **Yönlendirme:** React Router DOM (v7)
